# PDFforge — Free PDF Suite

90+ PDF tools. No login. No uploads to servers. 100% free.

## Deploy to Vercel
1. Push to GitHub
2. Import at vercel.com/new (auto-detects Next.js)
3. Deploy

For AI tools (Summarise, Translate, Chat), add `ANTHROPIC_API_KEY` in Vercel environment variables.

## Local dev
```bash
npm install && npm run dev
```
